# PDFs das Mensagens ao Congresso Nacional (2023 a 2026)

Cópias dos quatro documentos oficiais, redistribuídas sem alteração porque os endereços do gov.br mudam. Endereços de origem no momento da extração (Seção 7 do artigo):

- 2023: https://www.gov.br/planalto/pt-br/acesso-a-informacao/acoes-e-programas/governanca/mensagem-ao-congresso-nacional/MensagemaoCongressoNacional2023.pdf
- 2024: https://www.gov.br/planalto/pt-br/acesso-a-informacao/acoes-e-programas/governanca/mensagem-ao-congresso-nacional/mensagemaocongressonacional2024_vf.pdf
- 2025: https://www.gov.br/planalto/pt-br/acesso-a-informacao/acoes-e-programas/governanca/mensagem-ao-congresso-nacional/mcn2025digitalv1.pdf (o notebook o referencia como MensagemCongressoNacional2025.pdf)
- 2026: https://www.gov.br/casacivil/pt-br/.arquivos/mensagem-ao-congresso-nacional-2026.pdf

Depois de colocar os quatro arquivos nesta pasta, gere os hashes com `sha256sum *.pdf > SHA256SUMS.txt` (ou `shasum -a 256 *.pdf` no macOS) e inclua o arquivo no commit. O hash do corpus limpo (`dados/corpus_v3_paragrafo.csv`) está no certificado da execução.
